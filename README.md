## 🚀 Funcionalidades

O portfólio foi construído do zero, focado em performance, design moderno e usabilidade. Principais destaques:

* **Hero Section Dinâmica:** Apresentação inicial com animação de Terminal (simulando a inicialização de um servidor Python/FastAPI) e background interativo de partículas.
* **Carrossel de Projetos (Hero Card):** Exibição de projetos individuais em foco total (1 por tela), otimizando a leitura e a experiência do recrutador.
* **Carrossel de Imagens Interno:** Cada projeto possui sua própria navegação de telas/prints do sistema.
* **Interface Responsiva:** Layout que se adapta perfeitamente a celulares, tablets e desktops de telas grandes.
* **Links Diretos:** Integração automática com cliente de E-mail (Gmail) e Discador de Chamadas no rodapé.

## 🛠️ Construído com

Este projeto é um site estático (Frontend) criado para destacar minhas habilidades principais. Foram utilizadas apenas tecnologias base, sem uso de frameworks externos de CSS, garantindo controle total sobre o layout:

* **HTML5:** Semântica e estruturação sólida.
* **CSS3:** Variáveis (Custom Properties), Flexbox, Grid, Animações e Media Queries.
* **JavaScript (Vanilla):** Lógica matemática para navegação dos carrosséis dinâmicos e interações de interface.
* **FontAwesome:** Biblioteca de ícones vetorizados.

*(Apesar deste repositório focar no frontend do portfólio, minha stack principal é focada no Backend com Python, Java, C#, FastAPI e Bancos de Dados).*
